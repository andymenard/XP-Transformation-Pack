# XPlasma Plus tutorials

> [!WARNING]
> This project is **vibecoded** and is a public beta. Hands-on testing is limited to **Asahi Linux ARM64** and **Kubuntu on Intel/AMD x86-64**. Issues are expected. Back up your data and system configuration before installing. The installer's recovery backup is not a replacement for your own backup.

These tutorials describe **1.0.1 Public Beta**. Start with the compatibility guide, then follow the installation tutorial.

## What the beta includes

The XP desktop is selected by default: visual styles, application controls, Start/taskbar/clock, icons, pointers, fonts, sounds, wallpapers, shortcuts, selection/snapping effects, caption animations, session dialogs and the available lock/login/boot/splash integrations. **IE6 Firefox is optional.** XP replacement applications, games, custom tray menus, Codex additions and OTA updates are excluded.
