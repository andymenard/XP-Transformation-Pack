# Tux Start logo

The user-supplied Downloads/Tux.png replaces the former pixel artwork.
The supplied file is lossless WebP despite its extension; the bundled PNG
has exactly the same RGBA pixels and dimensions, without resizing.
Tux artwork: Larry Ewing and The GIMP; see COPYING-TUX for attribution.
The editor embeds this image; no ISO or download is needed.

## Classic KDE Start logo

The user's supplied klogo-classic.svg is retained as kde-classic.svg.
kde-crystal.png is a 256px transparent Qt SVG rendering of that exact classic
source. Its legacy filename is retained so existing saved checkbox selections
continue to work; the artwork is no longer the bright Crystal logo.
