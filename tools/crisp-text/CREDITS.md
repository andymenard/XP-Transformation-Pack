XPlasma Tahoma Pixel Regular and Bold are derived from Microsoft's original
Windows XP Tahoma fonts. Glyph bitmaps were captured using Windows XP SP3
(build 2600), GDI GetGlyphOutlineW in monochrome mode at 11 pixels, with genuine
regular and bold faces. Microsoft retains copyright in the source letterforms.
The generated assets retain the original fonts' editable-embedding flag; they
are not relicensed under the generator code's GPL license. Capture and generated
font hashes are recorded in the separately supplied JSON provenance files.
Microsoft Tahoma information: https://learn.microsoft.com/en-us/typography/font-list/tahoma

The numbered XPlasma Tahoma Pixel optical families are stem-balanced
adaptations of those same captured Microsoft letterforms for fractional
scaling. They retain Microsoft attribution and the same embedding flag.
